# ТЭМ18ДМ — Электрический тренажёр

Учебный проект для ТЭМ18ДМ 13-й серии с ЭСУВТ.

## Как открыть на компьютере
Открой `index.html` в браузере. Для проверки интерфейса установка дополнительных программ не требуется.

## Как опубликовать через GitHub Pages
1. Создай новый публичный репозиторий GitHub, например `tem18dm-trainer`.
2. Загрузи в корень репозитория все файлы и папки этого проекта.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку **main**, папку **/(root)** и нажми **Save**.
6. Через некоторое время GitHub покажет адрес опубликованного приложения.

## Установка на Android
Открой опубликованный адрес в Chrome на Android → меню браузера → «Установить приложение» или «Добавить на главный экран».

Это учебная заготовка, не сертифицированная документация и не средство управления локомотивом. Все реальные цепи, блокировки, номера проводов и выдержки времени должны быть сверены с исходной схемой и руководством для конкретного исполнения локомотива.
